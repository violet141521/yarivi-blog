# Como Inserir Imagens nos Artigos HTML

## banco-digital-vs-tradicional-2026

### 1. Meta Tags (no <head>)
```html
<!-- Open Graph / Social Media -->
<meta property="og:image" content="https://yarivi.com/imagens/banco-digital-vs-tradicional-2026.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:image" content="https://yarivi.com/imagens/banco-digital-vs-tradicional-2026.png">
```

### 2. Hero Image (topo do artigo)
```html
<!-- Imagem Hero (antes do H1) -->
<figure class="art-hero">
    <img
        src="../imagens/banco-digital-vs-tradicional-2026.png"
        alt="Comparação visual entre banco digital e banco tradicional - segurança e tecnologia"
        loading="lazy"
        decoding="async"
    >
    <figcaption style="font-size: 0.85rem; color: var(--text-3); margin-top: 0.5rem;">
        Ilustração: Fintech
    </figcaption>
</figure>
```

### 3. Inline Image (dentro do artigo)
```html
<figure class="art-inline-img" style="margin: 2rem 0; text-align: center;">
    <img
        src="../imagens/banco-digital-vs-tradicional-2026.png"
        alt="Comparação visual entre banco digital e banco tradicional - segurança e tecnologia"
        loading="lazy"
        style="max-width: 100%; height: auto; border-radius: var(--radius-lg);"
    >
```
