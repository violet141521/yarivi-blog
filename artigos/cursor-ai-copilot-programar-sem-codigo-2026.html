Um vice-diretor de escola criou um app em dois dias — sem escrever uma linha de código

No interior da Austrália, um administrador escolar descreveu em inglês o que queria: um sistema de achados e perdidos para a escola. Dois dias depois, o app estava funcionando. Não contratou um desenvolvedor. Usou o Cursor. Esse tipo de história está virando rotina — e o Brasil está chegando atrasado nessa onda.

O que mudou para tornar isso possível agora

Ferramentas de IA para código não são novas. O GitHub Copilot existe desde 2021. Mas até 2024, usar essas ferramentas ainda exigia saber programar — a IA era uma assistente do desenvolvedor, não uma substituta do conhecimento técnico.

O que mudou são dois fatores combinados: os modelos de linguagem ficaram muito melhores em entender o que alguém quer dizer versus o que escreveu exatamente, e as plataformas evoluíram para aceitar instruções em linguagem natural sem pré-requisito de sintaxe de programação.

O resultado é que hoje existem duas categorias de ferramentas: as que ajudam programadores (GitHub Copilot, Cursor usado profissionalmente) e as que permitem que qualquer pessoa crie aplicações (Lovable, Bolt, v0, Cursor em modo iniciante). Este artigo cobre as duas — porque dependendo do que você quer construir, a escolha muda.

O GitHub Copilot chegou a 4,7 milhões de assinantes pagos em janeiro de 2026 — crescimento de 75% em um ano. Está presente em 90% das empresas da Fortune 100 e 60% dos assinantes usam o Copilot Chat diariamente. (Fonte: GitHub Blog e Axis Intelligence, 2026)

GitHub Copilot: o copiloto dos programadores que virou ferramenta de todos

O GitHub Copilot nasceu dentro do editor de código VS Code, criado especificamente para desenvolvedores. Mas ao longo de 2025 a Microsoft o expandiu de formas que chegaram às pessoas sem formação técnica.

A versão atual tem três modos de uso:

  • Completação de código — você começa a escrever, a IA termina. Para programadores, é como ter um parceiro que conhece todas as bibliotecas existentes.
  • Chat — você faz perguntas sobre o seu projeto em linguagem natural. "Explique o que esse trecho faz." "Por que esse erro está acontecendo?" "Como faço para o botão ficar vermelho?"
  • Copilot Workspace — você descreve uma tarefa inteira e o Copilot cria um plano, escreve o código e executa. É o modo mais próximo do "escreva o que quer e receba o resultado".

Para alguém sem experiência em programação, o Copilot Workspace é o ponto de entrada mais acessível — você descreve o projeto como descreveria para um colega, e a IA interpreta e executa. O desafio é que ainda requer uma conta no GitHub e alguma familiaridade com o ecossistema de desenvolvimento.

Cursor: o editor de código para quem não sabe programar (mas quer aprender com a IA)

O Cursor é um editor de código construído sobre o VS Code — o mais popular do mundo — mas redesenhado em torno de um princípio diferente: a IA entende o projeto inteiro, não só o trecho que você está escrevendo.

Para um não-programador, os três modos do Cursor funcionam assim:

Tab — Completação linha a linha Você escreve ou cola um texto, e o Cursor completa o restante da linha ou bloco. Como o autocomplete do Gmail, mas para código. Pressione Tab para aceitar.
Chat — Perguntas sobre o projeto (Cmd+L) "O que esse arquivo faz?" "Por que o botão não aparece?" "Como faço para isso funcionar no celular também?" — em português. O Cursor lê o contexto do projeto antes de responder.
Agent — Tarefa completa em múltiplos arquivos (Cmd+Shift+I) Você descreve o que quer construir. O Cursor cria, edita e conecta os arquivos necessários automaticamente. É o modo que o vice-diretor australiano usou.

Um diferencial prático do Cursor é o arquivo .cursorrules — um documento de texto onde você escreve instruções permanentes para a IA, em português: "Sempre use cores azuis. Não use termos técnicos nos comentários. Este projeto deve funcionar em celular." A IA respeita essas regras em todas as sessões.

Lovable, Bolt e v0: para quem quer resultado, não aprendizado

Se o Cursor é para quem quer entender o processo, as plataformas no-code com IA são para quem quer o produto final sem ver uma linha de código. O mercado tem três nomes principais em 2026:

  • Lovable — especializado em criar aplicativos web completos a partir de uma descrição. Tem interface visual e permite arrastar componentes depois que a IA gera a base. Plano gratuito com limite de tokens; plano pago a partir de US$ 20/mês.
  • Bolt (da StackBlitz) — roda inteiramente no navegador, sem instalar nada. Você descreve, o app aparece em tempo real na tela ao lado. Bom para quem quer testar rápido.
  • v0 (da Vercel) — focado em criar componentes visuais de interface. Excelente para criar formulários, dashboards e seções de site com design profissional. Mais técnico que o Lovable, mas muito acessível para quem quer um resultado visual bonito.

Casos reais: o que pessoas comuns já construíram

O vice-diretor australiano é um dos exemplos mais citados na comunidade de IA aplicada à educação. Ele descreveu o projeto em inglês no Cursor, recebeu sugestões, testou, pediu ajustes, e em dois dias tinha um app funcional de achados e perdidos com banco de dados, fotos e notificações — algo que teria custado R$ 15–30 mil para encomendar de uma empresa de desenvolvimento.

Em 2025, uma professora de matemática do interior de São Paulo usou o Lovable para criar um simulador de bolsa de valores para usar com alunos do ensino médio. Levou duas horas. O simulador tinha preços em tempo real (via API gratuita), gráficos e placar dos alunos. Hoje é usado por três escolas da região.

No Rio de Janeiro, um nutricionista criou um calculador de dieta personalizado com interface mobile usando o Bolt. Compartilhou com pacientes via link — sem precisar pagar por uma assinatura de app ou contratar um desenvolvedor.

⚠️ O limite que as IAs ainda não cruzaram

Criar um app simples com IA ficou acessível para qualquer pessoa. Mas há um ponto onde a mágica para: segurança e escalabilidade.

O código gerado por IA funciona, mas frequentemente não segue as melhores práticas de segurança. Para um simulador educativo ou um app interno de escola, isso não é problema. Para um sistema com dados de saúde, pagamentos ou informações pessoais de clientes, o código precisa de revisão por um desenvolvedor experiente.

A metáfora certa: é como um estagiário muito rápido e criativo. Produz resultado impressionante para a maioria das tarefas, mas em projetos críticos você quer que um sênior revise o trabalho antes de ir ao ar.

Perguntas frequentes

Preciso de algum conhecimento técnico para usar o Cursor?

O mínimo necessário é saber descrever o que você quer. O Cursor cuida do código. O que ajuda é saber verificar se o resultado faz o que você pediu — isso não exige programar, só testar. Para projetos simples (calculadora, lista de tarefas, página pessoal), não há barreira real.

Qual a diferença entre Cursor e ferramentas como Lovable e Bolt?

Cursor é um editor onde você vê o código sendo gerado e pode editar manualmente. Lovable, Bolt e v0 são plataformas onde você descreve o que quer e o app aparece pronto, sem ver código. Para quem quer aprender a programar com IA: Cursor. Para resultado rápido sem aprendizado técnico: Lovable ou Bolt.

GitHub Copilot é pago? Tem versão gratuita?

Tem versão gratuita com 2.000 completações de código por mês — suficiente para testar e projetos pessoais pequenos. O plano Pro custa US$ 10/mês. Estudantes universitários podem solicitar acesso gratuito ilimitado pelo GitHub Education.

O código que a IA gera é confiável para usar em produção?

Para projetos pessoais e internos: sim, com revisão mínima. Para aplicações com dados sensíveis (saúde, financeiro, informações pessoais de terceiros): o código precisa de revisão por um desenvolvedor experiente, especialmente nas partes de segurança. Pense nisso como código de estagiário muito rápido — competente, mas que merece uma segunda olhada em projetos críticos.

Resumo em 5 pontos

  1. Criar um app sem programar ficou real em 2026 — ferramentas como Cursor, Lovable e Bolt permitem descrever o que você quer em português e receber código funcional.
  2. GitHub Copilot domina o mercado profissional — 4,7M assinantes, presente em 90% das maiores empresas do mundo, com crescimento de 75% ao ano.
  3. Cursor é o melhor ponto de entrada para iniciantes — especialmente o modo Agent, que executa tarefas completas a partir de uma descrição em linguagem natural.
  4. Lovable, Bolt e v0 são para quem quer resultado sem ver código — perfeitos para criar apps funcionais em horas, sem nenhum pré-requisito técnico.
  5. O limite é segurança em projetos críticos — para apps simples e internos, a IA entrega; para sistemas com dados sensíveis, o código precisa de revisão humana especializada.
